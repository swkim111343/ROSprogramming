1. 미들웨어(middleware)란 무엇인가?
    - 운영체제와 애플리케이션 사이에서 서로 다른 프로그램이나 시스템이 통신하고 데이터를 주고받을 수 있도록 중간에서 연결해 주는 소프트웨어

2. 분산컴퓨팅(distributed computing)에 대하여 조사하시오.
    - 여러 대의 컴퓨터가 네트워크로 연결되어 하나의 시스템처럼 작업을 나누어 처리하는 기술(클라우드 컴퓨팅, 분산 데이터베이스, 빅데이터 처리 시스템)
3. 네트워크 통신 기술에 대하여 조사하라.
    - TCP/IP: 인터넷에서 가장 기본적으로 사용되는 통신 방식
    - TCP: 데이터의 정확한 전달과 순서를 보장
    - UDP: 데이터 전달 속도가 빠르지만 전달을 보장하지 않음
    - HTTP/HTTPS: 웹에서 서버와 클라이언트가 통신할 때 사용
    - MQTT: IoT 환경에서 센서와 서버 간의 데이터 통신에 많이 사용
    - DDS: 로봇, 자율주행 등 실시간 분산 시스템에서 사용

4. RTPS(real-time publish subscribe) 프로토콜에 대하여 조사하시오.
- 실시간 분산 시스템에서 데이터를 주고받기 위한 Publish-Subscribe 방식의 통신 프로토콜
- RTPS에서는 데이터를 제공하는 Publisher와 데이터를 받는 Subscriber가 직접 연결되지 않음

5. DDS의 동적검색(Dynamic Discovery) 기능을 조사하시오.
    - 네트워크에 새로운 Publisher나 Subscriber가 참여했을 때 서로를 자동으로 찾아 통신할 수 있도록 하는 기능
    - 프로그램에서 각각의 노드가 다른 노드의 IP 주소나 위치를 일일이 설정하지 않아도 됨
    - 새로운 노드 실행 → DDS가 자동 검색 → 통신 가능한 노드 확인 → 데이터 통신

6. ROS1과 ROS2의 통신 방식의 차이를 설명하시오.
| 구분 | ROS1 | ROS2 |
|---|---|---|
| 통신 구조 | ROS Master 중심 | DDS 기반 |
| 미들웨어 | ROS 자체 통신 시스템 | DDS/RTPS |
| Discovery | ROS Master를 이용 | DDS가 자동 Discovery |
| 실시간성 | 제한적 | 향상됨 |
| 분산 시스템 | 설정이 필요함 | 분산 환경에 적합 |
| 보안 | 기본 지원이 부족함 | DDS 기반 보안 기능 지원 |
| 임베디드/로봇 적용 | 상대적으로 제한적 | 다양한 환경 지원 |

7. ROS2에서 DDS 기술을 도입한 이유를 설명하라.
    - 로봇 시스템의 분산 통신, 실시간성, 안정성 및 확장성을 높이기 위해서

8. 비슷한 통신 기술인 MQTT와 DDS의 차이를 설명하라.
| 구분 | MQTT | DDS |
|---|---|---|
| 주요 목적 | IoT 및 간단한 메시지 전달 | 실시간 분산 시스템 |
| 구조 | Broker 중심 | 기본적으로 Broker 없이 직접 통신 가능 |
| 실시간성 | 상대적으로 낮음 | 높은 실시간성 지원 |
| Discovery | Broker를 통해 관리 | Dynamic Discovery 지원 |
| QoS | 지원 | 다양한 QoS 지원 |
| 사용 분야 | IoT, 센서, 서버 | 로봇, 자율주행, 산업 시스템 |
| 통신 방식 | Topic 기반 | Topic 기반 |
