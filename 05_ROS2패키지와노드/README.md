## 과제
1. 패키지, 노드, 메시지, 메시지통신, 토픽, 서비스, 액션, 파라미터를 구분하여 설명하라.
    - 패키지(package) : 하나 이상의 노드 또는 노드 실행을 위한 정보 등을 묶어 놓은 것
    - 노드(node) : 최소 단위의 실행 가능한 프로세스, 하나의 실행가능한 프로그램
    - 메시지(message) : 노드와 노드 사이에 주고받는 데이터
    - 메시지통신 : 모든 메시지 통신은 토픽의 발행(publish)과 구독(subscribe)의 개념을 이용
    - 토픽 : Publisher와 Subscriber가 데이터를 주고받을 때 사용하는 이름이 지정된 통신 채널
    - 서비스 : 한 노드가 다른 노드에 요청(Request)을 보내고 결과(Response)를 한 번 받아오는 방식. 즉, 요청-응답 통신
    - 액션 : 시간이 오래 걸리는 작업을 수행할 때 사용하는 통신 방식. 목표(Goal)를 전달하고 진행 상태(Feedback)와 최종 결과(Result)를 받을 수 있음
    - 파라미터 : 노드의 동작을 설정하기 위한 설정값. 예: 속도, 센서 주기, 임계값 등
