## 실습과제 1
1. 패키지를 구성하는 가장 중요한 필수 파일 2가지는 무엇인가?
    - package.xml : ROS 2 패키지의 기본 정보를 정의하는 파일
    - CMakeLists.txt : CMake 기반 패키지의 빌드 설정 파일

2. xml 파일형식에 대하여 조사하시오.
    - XML(Extensible Markup Language)은 데이터를 저장하고 전달하기 위해 사용하는 확장 가능한 마크업 언어

3. ament_cmake와 CMake의 차이를 설명하시오.
    - CMake가 일반적인 빌드 시스템이고, ament_cmake는 ROS 2에 맞게 CMake를 확장한 빌드 시스템이라는 것
